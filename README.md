# AP Flour

All-purpose play tools for quick group decisions. The v1 direction is a local-first PWA for mobile, web, and iPad.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Local-first PWA baseline

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Planned v1 Scope

- Dice Roller
- Spin Wheel
- Random Picker
- Score Counter
- Timer / Stopwatch
- Local saved presets
- English and Thai UI
- Dark mode
- Runtime-only cheat mode unlocked with a 4-digit admin PIN
